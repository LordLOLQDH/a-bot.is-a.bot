# A-BOT.IS-A.BOT

A-BOT.IS-A.BOT is a small, multi-page creative website built around one simple digital identity: a bot is a bot.

## Pages
- `index.html` — Home / project introduction
- `bot.html` — Entity profile
- `lab.html` — Interactive browser experiments
- `protocol.html` — Project notes and technical status

## Design
A light editorial interface with electric cobalt blue, acid lime, oversized typography, technical labels and responsive navigation.

## Features
- Responsive navigation for mobile and desktop
- Live local clock on the home page
- Interactive terminal with local demo commands
- Random bot-thought generator
- Small classification quiz
- No backend, account system, analytics or external AI connection

## Run locally
Open `index.html` in a modern browser.

## GitHub Pages
To publish, open **Settings → Pages** in the repository and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
