03 / PULL REQUESTS

Code beitragen.

Forke das Repository, erstelle einen Branch, ändere die Dateien und pushe deinen Branch. Öffne danach auf GitHub einen Pull Request gegen main. Ein Pull Request kann Änderungen vorschlagen, aber nicht automatisch veröffentlichen. Du brauchst ein GitHub-Konto.
