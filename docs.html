01 / OVERVIEW

Was ist A-BOT.IS-A.BOT?

A-BOT.IS-A.BOT ist ein kreatives, mehrseitiges Webprojekt rund um eine einfache digitale Identität: Ein Bot ist ein Bot. Die Website ist ein Experiment mit Design, Browser-Interaktionen und Open-Source-Zusammenarbeit.

02 / FEATURES

Was kann die Website?

  • Mehrere responsive Seiten mit gemeinsamer Navigation.
  • Deutsch/Englisch-Umschaltung.
  • Interaktives Demo-Terminal und kleine Browser-Experimente.
  • Kontaktformular, das eine E-Mail im installierten Mailprogramm vorbereitet.
  • GitHub-basierte Fehlerberichte, Vorschläge und Pull Requests.
03 / TECHNOLOGY

Wie ist es gebaut?

Die Website verwendet HTML, CSS und JavaScript ohne Build-Schritt. Die interaktiven Demos laufen lokal im Browser. Es gibt aktuell keinen Server, keine Datenbank und keine echte KI-API.

HTML · CSS · Vanilla JavaScript · GitHub Pages
04 / PRIVACY

Datenschutz

Die statischen Demos senden keine Formulardaten an einen eigenen Server. Das Kontaktformular öffnet dein E-Mail-Programm. Beim Wechsel zu GitHub gelten die Datenschutz- und Nutzungsbedingungen von GitHub.

05 / HOSTING

Selbst hosten

Repository forken oder klonen, die Dateien im Root-Verzeichnis lassen und GitHub Pages unter Settings → Pages aktivieren. Als Quelle main und /(root) auswählen.
