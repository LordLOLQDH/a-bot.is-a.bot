01 / ABOUT

Was ist A-BOT.IS-A.BOT?

Ein kreatives Open-Source-Webprojekt rund um eine digitale Bot-Identität. Die Website ist ein interaktiver Ort für Experimente, Ideen und Zusammenarbeit.

02 / FEATURES

Was kann ich hier machen?

  • Im Kontrollzentrum Fehlerberichte und Funktionsideen vorbereiten.
  • Pull-Request-Assistent für bereits hochgeladene Branches.
  • Lokale Notizen, die auf deinem Gerät gespeichert werden.
  • Terminal-Demo und kleine interaktive Experimente.
03 / TECHNOLOGY

Wie funktioniert das?

HTML · CSS · JavaScript · GitHub Pages. Die Website benötigt keinen Build-Schritt. Lokale Funktionen laufen direkt im Browser.

04 / PRIVACY

Was wird gespeichert?

Die Notizfunktion speichert Inhalte nur in localStorage auf deinem Gerät. Formulare öffnen GitHub oder dein Mailprogramm. Es gibt keinen eigenen Server und kein Tracking.

05 / CONTRIBUTE

Mitmachen

Nutze Mission Control, um Vorschläge einzureichen oder einen Pull Request vorzubereiten. GitHub-Anmeldung ist für das tatsächliche Einreichen erforderlich.
